# Autofix

Enterprise Incident & Operations Management Portal — frontend prototype.

## Stack
- React
- TypeScript-ready project structure (current prototype uses JSX)
- Vite
- Lucide icons

## Run
```bash
npm install
npm run dev
```

## Next build steps

3. Add PostgreSQL schema and migrations.

6. Containerize with Docker.
7. Deploy to Azure after the application is functionally complete.
